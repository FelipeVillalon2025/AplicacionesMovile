Guía de Primeros Auxilios - Aplicación para AndroidCaptura de pantalla de la app <!-- **Nota:** Reemplaza esto con una URL a una captura de pantalla de tu app -->Una aplicación móvil esencial, desarrollada en Kotlin y Jetpack Compose, que ofrece instrucciones claras y rápidas sobre cómo actuar ante emergencias médicas comunes.📝 Descripción del ProyectoGuía de Primeros Auxilios es una herramienta de bolsillo diseñada para proporcionar asistencia inmediata y accesible en situaciones críticas. La aplicación presenta la información de manera sencilla, dividiendo las emergencias por categorías y ofreciendo pasos concisos sobre "Cómo actuar" y "Qué no hacer".El objetivo principal es empoderar a personas sin conocimientos médicos para que puedan prestar una ayuda eficaz y segura mientras llega la asistencia profesional.🎯 ¿Para Quién es Esta Aplicación?Esta aplicación es ideal para:•Público general: Cualquiera que desee estar preparado para una emergencia en casa, en el trabajo o en la calle.•Padres y cuidadores: Para tener a mano una guía rápida sobre cómo atender accidentes comunes en niños y adultos.•Profesores y personal escolar: Una herramienta útil para responder a incidentes en el entorno educativo.•Empresas y lugares de trabajo: Como un recurso de seguridad complementario para los empleados.✨ Características Principales•Navegación Intuitiva: Una barra de navegación inferior (BottomNavBar) permite un acceso rápido a las secciones principales.◦🏠 Inicio: Una lista de emergencias agrupadas por categorías (Heridas Comunes, Traumatismos, etc.).◦🔍 Búsqueda en Tiempo Real: Filtra y encuentra emergencias al instante con solo escribir una palabra clave.◦⭐ Favoritos: Guarda las emergencias más importantes para ti con un solo toque y accede a ellas rápidamente desde su propia sección.◦📞 Contactos de Emergencia: Una lista predefinida con números de emergencia esenciales (Ambulancia, Bomberos, Policía) y espacio para añadir contactos personales.•Diseño Claro y Accesible:◦La información se presenta en tarjetas desplegables que mantienen la interfaz limpia y organizada.◦Un tema de color verde claro, diseñado para ser agradable a la vista y reducir la fatiga visual.•Arquitectura Moderna:◦Construida 100% con Jetpack Compose, el moderno kit de herramientas de UI de Android.◦Sigue el patrón de arquitectura MVVM (Model-View-ViewModel) y el Principio de Repositorio, lo que asegura un código desacoplado, escalable y fácil de mantener.🛠️ Tecnologías Utilizadas•Lenguaje: Kotlin•UI Toolkit: Jetpack Compose•Arquitectura:◦MVVM (Model-View-ViewModel)◦Patrón de Repositorio para la gestión de datos.•Componentes de Jetpack:◦ViewModel: Para gestionar el estado de la UI y la lógica de negocio.◦Navigation for Compose: Para la navegación entre las diferentes pantallas.◦StateFlow: Para una comunicación reactiva y eficiente entre el ViewModel y la UI.🚀
